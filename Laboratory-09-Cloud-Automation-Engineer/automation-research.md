# Automation Research

## Bash Script
- It tells the operating system which interpreter (specifically the Bash shell) should be used to read and execute the commands inside the script file.

## Variables
- It saves time and prevents typing mistakes. If the folder path ever changes in the future, you only need to update it once in the variable definition instead of fixing it everywhere throughout the script.

## Cron Job
- It allows servers to run repetitive automated tasks (such as backups or system updates) on a strict schedule without needing a human administrator to manually type commands or watch hundreds of servers around the clock.

# Final Reflection 

For our final lab, our group built a WordPress website with a MySQL database using Docker, inside an Ubuntu Server virtual machine. We secured it with UFW and a Docker firewall fix, automated nightly backups with a Bash script and cron, and documented everything on GitHub. My part, together with Hulaton, was Requirement 5: the GitHub repository and the errors we met. Documenting showed me that a system is only useful if other people can understand and rebuild it. Writing the README and operational manual forced me to understand every step, not just copy commands. I learned what each command does, why Docker Compose works like a recipe, and how volumes keep data safe even after a reboot.   Our biggest problem was installing Docker. The command failed with "Unable to locate package docker-compose-plugin," and after that, Docker, the docker group, and the docker command were all missing. At first these looked like separate problems, but they all came from one cause: Ubuntu's default repository did not have the plugin, so nothing was installed. Installing Docker from the official repository fixed everything at once. This taught me to look for the root cause instead of fixing each error one by one. We also got "No such file or directory" because we were in the wrong folder after logging in again, reminding me to always check my terminal location. The most surprising part was learning that Docker can skip UFW completely. Turning on a firewall is not enough if you don't understand how other tools change the rules. Testing it with a container on port 9090 made the problem and the fix clear. Each member handled one requirement, but every part depended on the others. The deployment needed the VM's IP, the firewall needed the right ports, and the backups needed the database container name. Good communication kept everything working together. This lab connected everything from the semester: Linux, Docker, security, automation, and documentation. I now feel more confident setting up and maintaining a real server.

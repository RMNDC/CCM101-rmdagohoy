# Microsoft Azure 

## Brief Overview
Microsoft Azure launched in 2010 and is deeply integrated with the Windows/Microsoft ecosystem, making it a natural fit for organizations already running Windows Server, Active Directory, or Microsoft 365.

## Global Infrastructure
Microsoft reports 70+ Azure regions (the largest headline count of any provider, though this includes announced and sovereign/government regions not all generally available). Check azure.microsoft.com/explore/global-infrastructure for current, GA-only figures.

## Cloud Management Console
The **Azure Portal** is the unified web console for managing Azure resources.

## Four Core Services
- **Azure Virtual Machines** – compute
- **Azure Blob Storage** – object storage
- **Microsoft Entra ID (formerly Azure AD)** – identity management
- **Azure SQL Database** – managed relational database

## Three Advantages
1. Seamless hybrid-cloud integration with on-premises Windows Server/AD via Azure AD Connect
2. Deep integration with Microsoft 365, Teams, and existing enterprise licensing agreements
3. Strong compliance certifications favored by government and regulated industries

## Typical Enterprise Use Cases
- Enterprises migrating existing Windows Server workloads
- Organizations extending on-prem Active Directory to the cloud
- Hybrid cloud deployments

## AWS Research

## Brief Overview
Amazon Web Services (AWS) offers a wide range of cloud services that organizations can use to build, deploy, store, and manage applications without owning and maintaining all of the
required physical infrastructure. AWS supports businesses of different sizes, from startups to large enterprises, by providing scalable and flexible cloud resources.

## Global Infrastructure
AWS has a global infrastructure made up of Regions and Availability Zones, along with additional infrastructure such as Local Zones and Wavelength Zones.
AWS operates roughly 39 geographic regions and 120+ Availability Zones worldwide (each region has at least 3 AZs), plus a large CloudFront edge network for content delivery.

## Cloud Management Console
The **AWS Management Console** is the web dashboard used to provision and monitor all AWS resources.
The console allows users to select an AWS Region and access services such as Amazon EC2, Amazon S3, Amazon RDS, and Amazon VPC.

## Four Core Services
- **Amazon EC2** – resizable virtual machines (compute)
- **Amazon S3** – object storage for files, backups, and static assets
- **Amazon VPC** – isolated virtual networking
- **AWS IAM** – identity and access management for users/roles/permissions

## Three Advantages
1. Broadest service catalog and most mature ecosystem of any provider
2. Large partner and marketplace ecosystem with extensive third-party integrations
3. Flexible pay-as-you-go pricing with a Free Tier for experimentation

## Typical Enterprise Use Cases
- Large-scale e-commerce platforms needing elastic scaling
- Big data analytics pipelines
- Media streaming infrastructure

# Google Cloud Platform (GCP) 

## Brief Overview
Google Cloud Platform launched publicly around 2008–2011 and is best known for data analytics, AI/ML, and container orchestration — Google created Kubernetes and open-sourced it.

## Global Infrastructure
GCP operates roughly 40+ regions and runs largely on Google's own private global fiber network rather than public internet peering, which tends to reduce inter-region latency. Check cloud.google.com/about/locations for current figures.

## Cloud Management Console
The **Google Cloud Console** is the web-based management interface for GCP resources.

## Four Core Services
- **Compute Engine** – virtual machines (compute)
- **Cloud Storage** – object storage
- **BigQuery** – serverless data warehouse/analytics
- **Google Kubernetes Engine (GKE)** – managed Kubernetes

## Three Advantages
1. Strongest native Kubernetes/container support of any provider
2. Leading AI/ML tooling (Vertex AI, TPUs, BigQuery ML)
3. Competitive, often simpler pricing with per-second billing

## Typical Enterprise Use Cases
- Data analytics and business intelligence platforms
- AI/ML research and training pipelines
- Containerized microservices at scale

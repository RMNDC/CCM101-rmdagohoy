## Compute Resources
Compute resources are the CPU and memory used to process instructions and run applications.
The cloud needs compute resources to run applications, services, and virtual machines, while allowing resources to be allocated based on workload requirements.
1 CPU core (Intel Xeon E312xx) and 1.9 GiB RAM, both from Checkpoint 2.

## Storage Resources

What is it? Storage resources provide space for storing the operating system, applications, files, and other data.
The cloud needs storage resources to store data persistently and provide applications with access to the information they need.
`/dev/vda1` (19G), `/dev/vda16` (881M), and `/dev/vda15` (105M) disks from Checkpoint 2.

## Networking Resources

Networking resources allow computers, virtual machines, and applications to communicate with each other.
The cloud needs networking resources so users, applications, servers, and other cloud services can communicate and exchange data.
Hostname `ubuntu` and IP address `172.30.1.2` from Checkpoint 2.

## Operating System

An operating system manages the computer's hardware and software resources and provides a platform for running applications.
Why does the cloud need it? The cloud needs an operating system to manage compute, storage, networking, processes, and applications within virtual machines and other cloud environments.
Ubuntu 24.04.4 LTS with kernel `6.8.0-136-generic` from Checkpoint 2.

# Cloud Provider Comparison

## Infrastructure Component Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---------------------------|-----|------------------|------------------------|
| Compute | EC2 (Elastic Compute Cloud) provides scalable virtual servers for running applications and workloads.  | Virtual Machines provides on-demand Windows and Linux virtual machines that can be scaled according to workload requirements. | Compute Engine provides virtual machines that run on Google's infrastructure, with preset or custom configurations. |
| Storage | S3 (Simple Storage Service) object storage for storing and retrieving data using buckets and objects. | Blob Storage scalable object storage for unstructured data, applications, archives, data lakes, and other workloads. | Cloud Storage cloud storage for storing data, with additional storage services such as Filestore for network-attached file storage. |
| Networking | VPC (Virtual Private Cloud) provides a logically isolated virtual network where AWS resources can be launched and connected. | VNet (Virtual Network) provides private, isolated networks for virtual machines and applications and can connect to on-premises networks. | VPC (Virtual Private Cloud) provides a virtual network that spans regions and supports subnets, network policies, and connectivity. |
| Identity and Access Management (IAM) | AWS IAM manages users, roles, credentials, and permissions for controlling access to AWS resources. | Microsoft Entra ID + Azure RBAC manages identities and controls access to applications, data, and Azure resources through role-based permissions. | Cloud IAM controls who can perform actions on Google Cloud resources using identities, roles, and permissions. |

## Guide Questions

1. **Which cloud provider offers the broadest range of services?**
   AWS offers one of the broadest ranges of cloud services. It provides many options for computing, storage, networking, databases, security, AI, and other cloud needs.

3. **Which cloud platform would you recommend for an organization that primarily uses Microsoft products?**
  I would recommend Microsoft Azure because it works well with Microsoft products and services. It provides strong integration with Windows, Microsoft 365, and Microsoft Entra ID.

4. **Which platform is widely recognized for AI, ML, and Kubernetes services?**
   Google Cloud Platform (GCP) is widely recognized for its AI, ML, and Kubernetes capabilities. It provides services such as Google Kubernetes Engine (GKE) and AI/ML infrastructure.

6. **What similarities did you observe among the three cloud providers?**
   All three providers offer similar core services for compute, storage, networking, and IAM. Their service names and specific features differ, but they provide the same basic infrastructure needed for cloud applications.

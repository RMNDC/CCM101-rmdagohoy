## Linux Commands Used
- sudo adduser (username) - to create a new user 
- sudo usermod -aG sudo (username) - to give the new user sudo privileges
- su - (username) - to switch to the new user account
- whoami - to show the current username
- pwd - to show the current working directory
- hostname - to show the system hostname
- cat /etc/os-release - to check the Linux distribution
- uname -a - to check the kernel version and details
- lscpu - to check CPU information
- free  - to check total memory
- df  - to check available disk space
- mkdir - to create folders
- cd - to move between directories
- ls - to list files and folders
- nano (filename).md - to create and edit Markdown files
- cat (filename).md - to view the content of a file
- mv - to move files into folders

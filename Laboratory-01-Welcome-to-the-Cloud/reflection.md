## Reflection 
This was my first time working with cloud computing. I did used a software called Oracle VM before, so I never knew that something like KillerCoda existed. It was a new and interesting experience for me. I learned how to create my first username in an Ubuntu server inside KillerCoda. I named it rmdagohoy, using the command sudo adduser (myusername). I also learned some basic CLI commands. The whoami command shows my current username. The pwd command shows my current working directory. The hostname command shows the hostname of the system. After that, I learned how to create a Markdown file. I used the nano command, followed by the file name and the .md extension, to create and open the file. I also learned how to create folders in Ubuntu using the mkdir command, followed by the folder name. Then, I used the ls command to view the folders I created. After finishing that part, I moved on to GitHub. There, I worked on Checkpoint 4, which involved creating my portfolio structure using the GitHub website. I actually wanted to try using the CLI method on the Ubuntu server through KillerCoda, but it was too laggy, and I could not focus well.
